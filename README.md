# Henrique Valle de Lima

I teach Algorithms and Programming and serve as Pedagogical Coordinator for Software Engineering at Universidade Evangélica de Goiás (UniEVANGÉLICA). I am a member of the Núcleo Docente Estruturante (NDE) for Software Engineering at Anápolis and Ceres and for Artificial Intelligence. I hold a PhD in Computer Science from Universidade Federal de Goiás (UFG) and work on 5G network slicing, resource allocation, and reproducible software for research and teaching.

## Selected projects

- **Robocode Classroom** deploys Classic Robocode for Java labs in a browser with Docker Compose and noVNC. At UniEVANGÉLICA, we use it across programming, front-end web development, and back-end API development courses. [Repository](https://github.com/henrivalle/robocode) · [Release](https://github.com/henrivalle/robocode/releases/tag/v0.1.0-rc.1)
- **Slice Admission Bench** is a public teaching tool inspired by my doctoral research. It compares admission policies under bandwidth and compute constraints using reproducible synthetic workloads. [Repository](https://github.com/henrivalle/slice-admission-bench)
- **LTE-U Coexistence Lab** is a public teaching tool inspired by my master's research. It estimates channel availability using synthetic observations. [Repository](https://github.com/henrivalle/lteu-coexistence-lab)
