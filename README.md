# Henrique Valle de Lima

I’m a professor and Software Engineering program coordinator in Brazil. I hold a PhD in Computer Science from Universidade Federal de Goiás (UFG). My work focuses on 5G network slicing, resource allocation, machine learning, and reproducible software for research and teaching.

## Selected projects

- **Slice Admission Bench** compares admission policies under bandwidth and compute constraints using reproducible synthetic workloads. [Repository](https://github.com/henrivalle/slice-admission-bench)
- **Robocode Classroom** runs Java programming labs in a browser using Classic Robocode, Docker Compose, and noVNC. [Repository](https://github.com/henrivalle/robocode) · [Classroom update](https://github.com/henrivalle/robocode/pull/1)
